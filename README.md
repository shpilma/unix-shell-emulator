# Эмулятор командной оболочки UNIX (Вариант №25)

## Описание
Эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS).

Поддерживает:
- REPL с приглашением `username@hostname:cwd$`
- Загрузку VFS из XML, работу в памяти, сохранение в XML
- Команды: `ls`, `cd`, `pwd`, `echo`, `touch`, `chmod`, `vfs-save`, `exit`
- Запуск стартового скрипта с остановкой при первой ошибке
- Параметры командной строки: `--vfs`, `--script`, `--debug`

## Требования
Python 3.9+

## Запуск

Интерактивный режим:
```bash
python src/main.py --vfs scripts/vfs_examples/minimal.xml
